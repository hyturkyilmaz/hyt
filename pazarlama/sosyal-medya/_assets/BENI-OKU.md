# Avatar

Bu klasöre fotoğrafını `avatar.jpg` (veya `avatar.png`) adıyla koy. Kare, en az 600x600 px, yüz ortada olsun.

Sonra repo kökünden:

```bash
cd pazarlama/sosyal-medya/_kaynak && node render.mjs && node render.mjs --dikey 02
```

Fotoğraf yokken son slaytta "HYT" baş harfli yer tutucu görünür.
