# Metin

## Açıklama kalıbı
```
[Kanca — slayt 1'in sözel hali]

[2-3 satır bağlam: ne oldu, ne zaman, kaynak adıyla]

[Kişisel gözlem: "Haberi okuyunca aklıma ... geldi"]

[Sosyolog bakışı: insanların bu değişime tepkisi, tek cümle]

[CTA: Yorumlara ANAHTAR yaz, ... DM'den göndereyim.]

[3-5 hashtag]
```
- 600-1.200 karakter. Paragraf ≤ 3 satır. Emoji ≤ 3.
- Ben dili, sahadan. Yasak: devrim, inanılmaz, oyun değiştirici, çığır açan, "hadi gelin".

## Tek yazım hatası
- Tam 1 hata, açıklama gövdesinde, klavye kayması: harf düşmesi veya yer değiştirmesi
  (ör. "müşterilerimzin", "hazırlk", "otamatik").
- Yasak bölge: kanca, CTA kelimesi, marka/ürün adı, rakam, hashtag, görseller, seslendirme, altyazı.
- Üretim notuna yaz: kelime, doğrusu, paragraf. Aynı kelime iki gönderide tekrar etmez
  (geçmiş: "müşterilerimzin" — 01).

## Seslendirme metni
- `tts` alanı okunuşa göre: "Claude" → "Klod", "DM" → "di em", rakamlar yazıyla.
- `altyazi` alanı ekranda görünen doğru yazım.
- Bölüm başına 1-3 kısa cümle; toplam 35-45 sn.
